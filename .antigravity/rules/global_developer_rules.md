# 🛑 REGLAS FUNDAMENTALES DE DESARROLLO PERMANENTE (Ingeniería JH)

## 1. CERO DATOS FICTICIOS O SIMULADOS
- NUNCA inventar, simular, mockear o generar datos/números ficticios bajo ningún concepto.
- Todo dato presentado debe ser 100% oficial, real, verificado y proveniente de fuentes o bases de datos auténticas.
- Si un dato no existe, no está disponible o el evento aún no ha ocurrido, se debe declarar estrictamente como "PENDIENTE / NO DISPONIBLE / EN CURSO", nunca inventar valores de relleno.

## 2. PREGUNTAR ANTES DE ASUMIR
- Si una instrucción, requisito o diseño no está 100% claro o presenta ambigüedad, el agente DEBE detenerse y preguntar directamente al usuario antes de ejecutar o compilar.
- No asumir lógica de negocio crítica sin consultar al desarrollador principal.

## 3. NOTA DE ACTUALIZACIÓN AUTOMÁTICA PARA PLAY STORE
- SIEMPRE que se compile un nuevo APK / AAB, se DEBE incluir automáticamente una nota breve y profesional de actualización ("Novedades de esta versión") formateada y lista para copiar y pegar en Google Play Console.
